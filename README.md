# Wage Calculator

**Wage Calculator** is a simple desktop application for calculating wages and salary.

The application is designed to make basic wage calculations quick and easy through a simple graphical interface.

## Features

* Simple and clear graphical interface
* Wage and salary calculation
* Easy to use
* Lightweight desktop application
* Windows and macOS support

## Technologies

* **C++**
* **Qt 6.11.2**
* **Qt Creator**

## Supported Platforms

### macOS

* Apple Silicon
* Qt 6.11.2
* macOS Release build

### Windows

* Windows 10 64-bit
* Windows 11 64-bit
* Qt 6.11.2 + MinGW 64-bit

## Installation

### macOS

1. Download the latest `wage-calculator-macOS.zip` from **Releases**.
2. Extract the ZIP file.
3. Open `mzda.app`.
4. The application should start without requiring Qt Creator to be installed.

### Windows

1. Download the latest Windows release from **Releases**.
2. Extract the downloaded ZIP file.
3. Open the extracted folder.
4. Double-click the `.exe` file to start the application.
5. If Windows displays a security warning, verify that the file was downloaded from this GitHub repository before allowing it to run.

The Windows version does not require Qt Creator to be installed.

## Building from Source

If you want to build the application yourself:

1. Install **Qt 6.11.2** and **Qt Creator**.
2. Clone or download this repository.
3. Open the `.pro` project file in Qt Creator.
4. Select the appropriate Qt kit for your operating system.
5. Select **Release** configuration.
6. Build the project.
